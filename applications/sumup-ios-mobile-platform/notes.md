## One deliberate style exception

The letter contains `Two enterprise apps, two teams, two release cycles, one API surface, and no ability to change either host app.` That is five commas and technically trips the comma-density check in `letter-critique`.

Kept on purpose. The rule exists to stop clauses being chained with `, and`, which is what Farrukh flagged. This is a parallel list where the accumulation is the point, and splitting it produces four choppy fragments that read worse. Flagged here rather than overridden silently. Say if you want it split.
